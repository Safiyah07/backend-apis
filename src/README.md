# Backend APIs

This repository showcases multiple backend APIs built with Node.js, Express.js and PostgreSQL.

## APIs Included

1. **Auth API** — User registration, login, JWT authentication, refresh token and access token renewal.  
   📂 [`src/api/auth/`](./auth)

2. **User API** — Basic CRUD operations on users.  
   📂 [`src/api/user/`](./user)

3. **Utility API** — Additional endpoints for data validation or business logic.  
   📂 [`src/utility/`](./utility)

Each folder function includes its own swagger documentation and test examples.
